# Creature mood source artwork

`CreatureMoodAtlas.png` is original AI-generated project artwork produced with
the built-in image-generation tool on September 20, 2026; no existing game's
graphics were copied. It has a genuine transparent background and twelve square
cells (four columns, three rows), with the last cell intentionally empty.

`../package-creature-mood-icons.ps1` resamples the eleven cells to the existing
64px runtime texture paths without changing their mood-state meanings. The
health-ring generator no longer overwrites the independently authored unhappy
icon. The runtime uses its existing 22px mood display.

Generation prompt: a transparent four-column, three-row production UI sprite
sheet for a dark medieval dungeon strategy game; simple bold small symbols,
hand-painted shaded enamel and worn metal, dark contours, restrained highlights,
gold/bronze accents, upper-left light, no labels or tile backgrounds. In order:
orange-red angry goblin; crimson furious goblin; gold coins/pay pouch; boot
leaving an open doorway; lavender knocked-out goblin; chicken drumstick; blue
sleeping face/crescent; dazed head/gold stars; iron bars/brass lock; crimson rally
banner; amber unhappy goblin; empty transparent cell. Consistent cell margins,
original artwork, readable at 22px, no copied game assets or watermark.
